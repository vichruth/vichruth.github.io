# Vichruth M. - Edge AI & ML Portfolio 

A high-performance, interactive personal portfolio website showcasing expertise in scalable Machine Learning, Computer Vision, and Edge-Native AI architectures. Designed with a sleek, technical aesthetic resembling modern AI development environments.

[![Live Demo](https://img.shields.io/badge/Live_Site-vichruth.github.io-10B981?style=for-the-badge)](https://vichruth.github.io)
[![Stack: React + Vite](https://img.shields.io/badge/Stack-React%20%2B%20Vite-3178C6?style=for-the-badge&logo=react)](https://react.dev/)

## Features

- **Interactive Edge AI Simulator:** A built-in sandbox UI that simulates precision casting (FP16/INT8), VRAM budget management, and real-time latency impacts on edge architectures.
- **Dynamic Neural Network Canvas:** A procedural, interactive node-link background built natively on the HTML5 Canvas API using generative particle physics.
- **Code Inspector Sandbox:** A syntax-highlighted IDE emulation window showcasing native PyTorch and Python implementation scripts.
- **Bento-Grid Specs Panel:** A structured, high-density layout mapping out deep learning frameworks, languages, and OS expertise.
- **Optimized & Responsive:** Fully responsive down to mobile viewports, adhering strictly to Tailwind's mobile-first breakpoints.

## Technical Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Motion (Framer Motion)
- **Icons:** Lucide React
- **Hosting:** GitHub Pages (Automated via Actions CI/CD)

## Local Deployment

To run this compilation environment locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vichruth/vichruth.github.io.git
   cd vichruth.github.io

    Install dependencies:
    (Ensure you have Node.js 18+ installed)
    code Bash

    npm install

    Start the local telemetry server:
    code Bash

    npm run dev

    The server will spin up on http://localhost:3000 or http://localhost:5173 depending on available network ports.

    Build for production:
    code Bash

    npm run build
