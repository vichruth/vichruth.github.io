# Vichruth M. | Edge AI & ML Portfolio

A highly optimized, interactive portfolio showcasing my research and projects in Computer Science, Machine Learning, Computer Vision, and Edge AI deployment. Built with a focus on dark-mode aesthetics, custom node-based visualizers, and interactive hardware parameter simulations.

## Live Preview
**[View Interactive Portfolio](https://vichruth.github.io)**

## Core Features
- **Neural Network Visualizer Background:** A custom interactive canvas representing an active ML network.
- **Edge AI Sandbox Simulator:** An interactive sandbox where users can adjust variables like Quantization (FP32 -> FP16 -> INT8) and VRAM limits to see simulated real-time impact on performance matrices natively in their browser.
- **Dynamic XCODE Source Inspector:** Review statistical weights, temporal vision pipeline logic, and architecture parameters via stylized source-code snippets.
- **Modular Project Architectures:** Extensive documentation logging of Transformer implementations (TransReID), LLMs (CodeT5), and Kaggle-winning machine learning algorithms seamlessly integrated into a fluid animated UI.

## Performance & Tech Stack
This site was built with a mobile-first, high-performance architecture utilizing:
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS (v4)
- **Animation:** Motion (framer-motion)
- **Icons:** Lucide React
- **Deployment Hub:** GitHub Actions to GitHub Pages (`ubuntu-latest` isolated container)

## Local Development
To run this project locally, execute the following commands in your terminal:
```bash
# 1. Clone the repository
git clone https://github.com/vichruth/vichruth.github.io.git

# 2. Enter directory
cd vichruth.github.io

# 3. Install dependencies
npm install

# 4. Spin up the Vite Dev Server
npm run dev
